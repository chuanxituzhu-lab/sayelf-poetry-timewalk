# C/E/S Evidence Chain

The public demo uses three layers so factual grounding and creative interpretation remain visible:

- **C — Content/Text:** wording that can be checked directly against the poem.
- **E — Evidence:** historical, biographical, textual, or contextual support.
- **S — Synthesis:** interpretation, scene design, prompt writing, and platform adaptation.

Use `C` and `E` to constrain the claims. Use `S` to create a coherent story and visual treatment. If a claim cannot be supported, label it as an inference or hypothesis and leave it for human review.

The continuity lock tracks person, object, space, light, and style so the image prompts and video storyboard prompts can be produced as a matched sequence.

Evidence can include primary texts, editions, classical commentary, modern scholarship, and attributed contemporary interpretation. A library catalog or search result is a discovery/metadata lead, not proof of an uninspected passage. See the [evidence-source index](evidence-source-index.md) for claim-level citation fields, verification states, and rights boundaries.
